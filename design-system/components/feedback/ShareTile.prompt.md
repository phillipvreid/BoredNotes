The export sticker you screenshot into the group chat — colored card, prompt + answer, wordmark footer. Heavier 6px shadow than an in-app card so it reads as a standalone object.

```jsx
<ShareTile cat="CONFESS" color="var(--bn-cat-confess)"
  prompt="A thing you pretend to like:"
  answer="Hiking. It's just walking, but upset." />
```
