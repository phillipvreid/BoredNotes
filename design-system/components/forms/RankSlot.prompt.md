A single podium row for a RANK prompt. The place number is a large hollow (outlined) numeral, slightly tilted, bleeding into the box. Three of these stack into the podium. There's deliberately no score — committing to an order IS the answer.

```jsx
<RankSlot place={0} value="Toucan Sam" />
<RankSlot place={1} value="Tony the Tiger" />
<RankSlot place={2} placeholder="tap to fill" onClick={pick} />
```
