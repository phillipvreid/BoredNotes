# Security & Encryption Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Protect user notes at rest via iOS Data Protection and surface a privacy disclosure for AI prompt generation.

**Architecture:** Two independent config/UI changes — one Expo build entitlement that enables OS-level file encryption, and one settings screen text update for AI privacy transparency. No logic changes, no new dependencies, no schema changes.

**Tech Stack:** Expo (managed workflow), React Native, `app.json` entitlements, `app/settings.tsx`

### Task 1: Add iOS Data Protection Entitlement

**Files:**
- Modify: `app.json` (ios section, lines 13–24)

- [ ] **Step 1: Add the entitlement to `app.json`**

Replace the `"ios"` block (currently ends at the closing brace after `infoPlist`) with:

```json
"ios": {
  "supportsTablet": false,
  "bundleIdentifier": "com.borednotes.app",
  "infoPlist": {
    "NSCameraUsageDescription": "BoredNotes uses the camera to attach photos to your entries.",
    "NSPhotoLibraryUsageDescription": "BoredNotes accesses your photo library to attach images to entries.",
    "NSLocationWhenInUseUsageDescription": "BoredNotes can tag your entries with where you wrote them.",
    "ITSAppUsesNonExemptEncryption": false
  },
  "entitlements": {
    "com.apple.developer.default-data-protection": "NSFileProtectionComplete"
  }
}
```

`ITSAppUsesNonExemptEncryption` stays `false` — iOS Data Protection is OS-provided and not subject to App Store export compliance.

- [ ] **Step 2: Verify the JSON is valid**

Run:
```bash
npx expo config --type introspect 2>&1 | head -5
```

Expected: no parse errors. If you see a JSON syntax error, fix it before proceeding.

- [ ] **Step 3: Commit**

```bash
git add app.json
git commit -m "feat: enable NSFileProtectionComplete for at-rest encryption"
```

### Task 2: Add AI Privacy Disclosure to Settings

**Files:**
- Modify: `app/settings.tsx` (Offline Mode row subtitle, around line 141)

- [ ] **Step 1: Update the Offline Mode row subtitle**

Find this text in `app/settings.tsx` (around line 141):

```tsx
<Text style={[styles.rowSubtitle, { color: colors.textMuted }]}>Use built-in prompts only, no AI</Text>
```

Replace with:


This replaces the old subtitle entirely — the new text is more informative and covers what the old text said.
