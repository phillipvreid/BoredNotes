Theme palettes

Six themes for the themes menu. Each one swaps the paper, ink, action color, and its own tint of the eight category hues — the sticker mechanics (keyline + flat offset shadow, tilts) stay the same in every theme. Each theme has its own light and dark mode.

What stays the same in every theme: the sticker mechanics (keyline + flat offset shadow, press behavior, hand-placed tilts), white text on every category chip, and the reserved-action rule — each theme's action color only ever means "do the thing" and always carries its theme's dark ink. Category hues are now tinted per theme, but each category keeps its hue family (REFLECT is always a blue, GOSSIP is always a red) so entries stay recognizable when you switch themes.
